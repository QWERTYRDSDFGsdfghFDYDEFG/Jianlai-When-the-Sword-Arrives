## 1. 一句话最终口径

**李槐是书院时期、尚未长开的东方少年：偏窄的小椭圆脸，浓而平直微挑的剑眉，清亮杏眼，短鼻小嘴，黑发高束成略乱的小丸髻；当前穿米白旧纹交领短袍、灰褐腰封和宽松灰裤，着交叉绑带布靴，腰悬双葫芦与一柄带青灰流苏的短刀。后续只允许改变表情、动作、镜头和场景，不允许重新设计脸、发型、服装层级与核心道具。**

---

## 2. 角色定位与整体气质

李槐不是沉稳成熟的少侠，也不是精修古偶少年。他是会把江湖话本当真、爱逞英雄、表演欲强，却仍带着书院少年稚气的人。

必须保持：

- 少年未雕琢感，身量轻、骨架尚未完全长开。
- 聪明、好胜、得意和认真可以同时存在。
- “装大侠”时是真投入，不是油滑耍帅。
- 有真实生活感和轻微风尘感，但不邋遢。
- 喜剧感来自过分认真和动作幅度，不来自丑化五官。

禁止偏移：

- 成熟青年侠客、冷面剑客或仙门天才。
- 偶像化古风美少年、网红脸、古偶精修脸。
- 幼儿化、包子脸、夸张萌系小男孩。
- 油腻痞笑、轻浮纨绔或滑稽丑角。

## 3. 脸部身份锁定

### 3.1 脸型与年龄感

必须保持：

- 偏窄的小椭圆脸，脸长略大于脸宽。
- 额头自然，不宽大；颧区平缓，不做成熟骨感。
- 少年面颊保留少量软感，但不圆、不鼓。
- 下颌线清楚而轻，下巴短、微收，不尖削。

禁止：

- 圆脸、包子脸、宽下颌、方脸。
- 成年男性的深凹面颊、突出颧骨和强硬下颌。
- 过长尖脸、网红锥子脸或女性化精致脸。

### 3.2 眉眼

必须保持：

- 黑色浓眉，眉形平直为主，外段轻微上挑。
- 眉眼距离偏近，形成认真、好胜的神气。
- 眼型为自然杏眼，眼裂中等，外眼角只轻微上扬。
- 黑色瞳仁清晰，眼神亮、直接、有少年人的主意。
- 得意时眉峰可松；认真和紧张时眉心可收，但眉形身份不变。

禁止：

- 超大圆眼、幼态萌眼、浓密偶像睫毛。
- 狭长丹凤眼、阴鸷眯眼、成熟媚眼。
- 过粗倒竖的怒眉或永久凶相。
- 空洞无神、阴沉老成的眼神。

### 3.3 鼻口与耳朵

必须保持：

- 鼻梁短而自然，鼻头小，刻画克制。
- 嘴型偏小，唇薄而自然，不做妆感。
- 静态嘴角可有轻微自信上扬，但不是固定坏笑。
- 张口呼喊时口型可以放大，闭口后必须回到小而利落的基础嘴型。
- 耳朵比例自然，贴近头部，不做精灵耳或夸张招风耳。

禁止：

- 高挺成人鼻、厚唇、明显唇色或精修妆感。
- 永久咧嘴、夸张龅牙、滑稽漫画口型。
- 用序-05喊话时的张口表情覆盖日常脸部标准。

---

## 4. 发型锁定

必须保持：

- 黑发，发量自然偏多。
- 前额为不规则碎刘海，长度落在眉上至眉间，不是整齐齐刘海。
- 两侧鬓发短而略乱，耳前可有少量碎发。
- 头顶高束成一个略松、略乱的小丸髻。
- 发髻以低调褐色布绳缠束，并由短木簪横向固定。
- 整体是少年自己束起的实用发型，允许少量毛躁和散发。

禁止：

- 披发、长马尾、双髻、冠发或仙侠高冠。
- 油亮整齐的古偶发套感。
- 把小丸髻画成巨大道士髻、花苞髻或女性发髻。
- 金玉发冠、华丽发饰、长飘带。

## 5. 当前服装标准

### 5.1 总体方向

必须保持：

- 宋韵基础上的书院少年短打与轻江湖感。
- 米白、灰褐、炭灰为主的低饱和高级灰配色。
- 真实棉麻布料、可见织纹、轻微使用痕迹。
- 上浅下深，腰部压深色，轮廓利落但不紧身。

禁止：

- 纯白仙袍、飘逸大袖仙服、盔甲或制式劲装。
- 鲜艳高饱和配色、大面积金纹、发光描边。
- 华丽贵族服、仙门弟子制服、网游侠客服。

### 5.2 上装结构

必须保持：

- 米白偏旧纸色的交领短袍，右衽关系清楚。
- 内层领口和袖口为中深灰色，形成稳定深浅层次。
- 外袍有非常克制的浅灰暗纹或自然布面纹理。
- 袖型宽松但实用，长度至手腕，不做拖垂广袖。
- 肩线自然，衣身不贴体，保留少年身形的轻薄感。

禁止：

- 取消深灰内领和袖口层次。
- 把浅色纹理画成华丽刺绣、龙纹、云雷金纹。
- 无袖、窄袖紧身或夸张水袖。

### 5.3 腰部、下装与鞋履

必须保持：

- 腰部使用多圈深灰褐布带缠束，正面可见实用绳结。
- 前方有灰褐色垂片或短围裳层，长度约至膝上至膝部。
- 下装为深灰褐宽松长裤，膝部和裆部有行动余量。
- 小腿至脚踝为深色布靴，外用浅褐布带交叉缠绑。
- 鞋底和绑带有轻使用痕迹，不做崭新皮靴。

禁止：

- 玉带、金属大腰带、复杂腰甲。
- 紧身裤、裙装、拖地袍摆。
- 高筒皮靴、仙侠战靴、现代鞋底结构。

## 6. 固定道具与场次道具

### 6.1 当前核心随身道具

- 腰间双葫芦：一大一小、天然棕色、并列悬挂，配青灰短穗；这是当前服装母版的重要识别点。
- 佩刀：腰侧单刀，深色缠柄，旧铜色护手与刀首，柄尾垂青灰流苏。
- 道具材质必须真实、克制、有使用感，不做发光法器。

### 6.2 场次限定道具

- 序-03：白鹿及牵引绳。白鹿是场次搭档，不是李槐永久贴身宠物标识。
- 序-05：不需要白鹿入画；李槐以伸手喝止、另一手扶刀完成英雄救场。

### 6.3 道具位置连续性

- 双葫芦固定在腰间与佩刀相对或错开的侧面，避免互相穿模。
- 佩刀保持同一侧与同一悬挂方向；镜像构图时须检查刀与葫芦是否被错误互换。
- 青灰流苏只作小面积强调色，不得变成长飘带。

禁止：

- 双剑、长剑、巨刀、弓箭、折扇或多余法器。
- 把葫芦夸张成巨大酒葫芦或发光宝物。
- 同一画面出现两柄刀、重复葫芦或道具穿过手臂和衣摆。

## 7. 体型与动作口径

必须保持：

- 少年身高与比例，头身比自然，不拉成长腿成年侠客。
- 肩不宽厚，胸背不肌肉化，四肢轻而有活力。
- 动作有主动性和表演欲，重心必须可信。
- 手掌、手指与刀柄比例自然，避免英雄动作导致手部异常放大。

场次口径：

- 序-03牵鹿登场：迈步入画、头略转向目标、神情得意；白鹿稍慢半拍，形成一主一从。
- 序-05英雄救场：宽步收势、身体由前冲转为立住；一手向前伸开喝止，另一手扶刀，豪气略过盛但不是战斗杀招。
- 普通表情或日常立绘：收回英雄动作幅度，保留少年人的机灵和自信，不永久叉腿喊话。

## 8. 基础表情标准

以 `lh_expression_sheet_basic_v1.png` 为准：

1. **得意**：眉眼放松，嘴角轻扬，带一点“我早有办法”的自信；不做油滑坏笑。
2. **认真装大侠**：眉心收紧，目光直视，嘴闭合或短句口型，一手握拳；认真多于凶狠。
3. **豪气过盛**：眉眼打开、张口呼喊、拳头举起，情绪外放但不扭曲脸部。
4. **稍显紧张但硬撑**：眉心紧、视线专注、可有一滴克制汗珠，嘴唇收住；不能变成恐惧哭脸。

允许新增：疑惑、惊讶、小声嘀咕、不服、尴尬、担心、放松微笑。新增表情必须沿用同一骨相、眉形、眼型和发型。

## 9. 允许变化与不可变化

允许变化：

- 表情肌、嘴型、视线方向。
- 手势、步态、站姿和身体朝向。
- 半身、全身、近景、中景及三分之四视角。
- 场景光线对固有色的合理影响。
- 场次明确要求的白鹿、牵绳等临时道具。

不可变化：

- 基础脸型、眉眼比例、鼻口尺度和少年年龄感。
- 碎刘海、高束小丸髻、褐色束绳和短木簪。
- 米白交领短袍、深灰内层、灰褐腰封、宽松灰裤、绑腿布靴的服装层级。
- 双葫芦、单刀和青灰流苏的当前道具体系。
- 非偶像化、非仙侠网游化的整体方向。

## 11. 出图验收清单

1. 第一眼是否仍是表情表里的同一个少年李槐。
2. 脸是否偏窄、尚未长开，而非圆萌或成年硬朗。
3. 是否保留浓平微挑眉、自然杏眼、短鼻小嘴。
4. 是否保留碎刘海、高束略乱小丸髻、褐色束绳和短木簪。
5. 是否为米白交领短袍与深灰内层，上浅下深。
6. 是否有多圈灰褐腰封、前垂片、宽松灰裤和绑腿布靴。
7. 双葫芦和单刀是否数量、位置、比例合理，没有穿模或镜像错位。
8. 表情是否符合“得意、认真装大侠、豪气过盛、紧张硬撑”的少年尺度。
9. 动作重心是否真实，喜剧感是否来自认真表演而非丑化。
10. 是否避免仙侠网游、古偶、偶像化和萌系偏移。
11. 场次图是否同时遵守 `script逐场分镜表.md` 的站位、动作与构图要求。

## 12. 执行优先级

1. 先用 `lh_expression_sheet_basic_v1.png` 锁脸。
2. 再用 `lh_action_c1_03_white_deer_entry_v1.png` 锁全身体型、服装和道具。
3. 序-05或其他大动作场景，再用 `lh_action_c1_05_hero_entry_v1.png` 锁动作张力。
4. 最后叠加具体分镜的站位、光线、镜头和场景要求。
5. 若脸部与动作完整性冲突，优先稳脸；若服装细节与动作可读性冲突，保留服装层级与核心识别点，减少非必要褶皱。
