# 陈平安固定脸部身份与当前服装标准

适用对象：`cpa/` 目录下陈平安的全部后续立绘、表情、动作版、章节版、场景版。

母版基准图：

- 脸部身份母版：`cpa_face_standard_01.png`
- 当前通用服装母版：`cpa_outfit_variant_06_warm_weather.png`
- `script.rpy` 陈平安服装母版：`c1_10_cpa_arrival_v14.png`
- 书箱唯一道具参考：`cpa_bookbox_ref.jpg`（`参考01·04`）
- 养剑壶主参考：`cpa_gourd_ref.png`（`参考01·05`）；壶形与红绳辅助参考：`cpa_gourd_structure_ref.jpg`（`参考01·06`）

2026-09-20 用户统一书箱与养剑壶造型：后续所有场次携行这两件道具时，按第 2.6、2.7 节执行；旧图中的开放背架、闭合箱或普通葫芦不得反向覆盖新标准。人物脸部、年龄、发型与衣物版型锁定不变；按用户最新要求，撤除旧腰间小布袋及其专用吊绳，不再纳入身份或服装标准。道具原图只提供器物信息，不借用图中人物或摄影、3D 渲染风格。

## 1. 目标定义

本标准的唯一优先目标，不是单独生成一张“更好看”的陈平安，而是建立陈平安的固定脸部身份标准，并在当前阶段锁定统一服装版本。

后续一切变化，必须建立在同一张脸、同一套当前服装的前提上进行：

- 脸型固定
- 五官比例固定
- 年龄感固定
- 气质底色固定
- 当前服装固定

允许变化的内容只有：

- 表情
- 动作
- 场景

禁止把每一张新图当成“重新设计一次陈平安的脸”或“重新设计一次陈平安的衣装”。

## 2. 五项硬锁定

以下五项是后续所有生成的最高优先级，任何一项漂移，都视为不合格。

### 2.1 脸型锁定

- 以 `cpa_face_standard_01.png` 为唯一脸型母版。
- 脸部整体为偏瘦长、收束明确的青年脸型。
- 额头、颧侧、下颌、下巴的收放关系必须保持一致。
- 下颌不能变宽，不能变圆，不能变成更尖锐的夸张 V 脸。
- 下巴长度和收束角度必须维持母版观感。

### 2.2 五官比例锁定

- 眉眼距离保持母版比例，不可随意拉近或拉远。
- 眼睛长度、开合度、眼尾走势、内外眼角关系保持母版比例。
- 鼻梁长度、鼻头位置、鼻尖落点保持母版比例。
- 人中长度、嘴宽、唇线厚薄和嘴角落点保持母版比例。
- 耳位、发际线与面部中轴关系不得随意改变。

原则：可以换表情，但不能换五官设计。

### 2.3 年龄感锁定

- 固定年龄感为 20-22 岁的年轻男子。
- 必须保留“青年已入世”的成熟度，不能画成少年感过强。
- 不能老化成 25 岁以上的沧桑脸，也不能幼化成 17-18 岁的稚气脸。
- 皮相应克制、自然，不要出现过度精修、过度艳化、过度偶像化处理。

### 2.4 气质底色锁定

陈平安的底色必须始终是：

- 沉静
- 可靠
- 自持
- 坚韧

允许在具体画面里出现：

- 轻微温和
- 疲惫
- 警觉
- 克制的怒意
- 压抑中的悲伤

但不允许整体气质改成：

- 轻佻
- 妖异
- 风流公子感
- 邪气反派感
- 过度柔媚
- 过度冷艳
- 过度热血少年漫主角感

原则：情绪可以波动，底色不能换人。

### 2.5 当前服装锁定

- 默认以 `cpa_outfit_variant_06_warm_weather.png` 为陈平安通用唯一服装母版。
- `script.rpy` 相关陈平安画面，以 `c1_10_cpa_arrival_v14.png` 为该场次唯一服装母版。
- 若不是 `script.rpy` 指定场次，仍回到 `cpa_outfit_variant_06_warm_weather.png` 的通用服装口径。
- 当前阶段默认固定为该图的暖天行路装，不再允许自由更换其他服装版本。
- 必须保持该图的整体服装结构关系，包括：
  - 灰蓝色短袖外袍
  - 白色内衫
  - 深色长裤
  - 腰间主绳带与单只养剑壶；撤除旧小布袋及其专用吊绳，保留主腰绳的结构和壶的短挂绳
  - 小腿绑带
  - 草鞋
  - 背后的青绿竹编长方敞口书箱，具体结构见第 2.6 节
- 允许出现轻微褶皱、污损、风尘感，但不允许改成另一套衣服、另一种剪裁、另一种配色方案。
- 不允许把当前服装替换成贵气长袍、飘逸仙侠装、厚重冬装、书生礼服或其他未批准版本。

原则：可以有使用痕迹，但不能换服装版本。

### 2.6 统一书箱标准（2026-09-20）

- 唯一结构参考为用户指定的 `cpa_bookbox_ref.jpg`：青绿色竹片编织的长方敞口箱，四角有高出箱口的竹节立柱，横向竹杆与藤绳绑扎形成清楚的框架。
- 箱侧按参考系挂斗笠与一双备用草鞋；按视角允许自然遮挡，不为展示挂件把箱体或四肢扭向镜头。
- 箱体贴合背部，背负绳带在肩部和箱体上都有明确连接，保留受力方向、衣料压痕与接触阴影；手握肩带时，肩、手、箱体三个接触位置必须同时成立。
- 这是所有后续场次的统一道具造型，取代旧开放背架与外挂行囊，也取代已停用菜单图的闭合箱特例；不再按场次切回旧造型。是否背负、放下或暂不入画仍服从剧情。
- 禁止改成无编织箱壁的开放背架、圆背篓、闭合硬箱、现代双肩包、金属箱或华贵发光法器；不新增文字、符号和印章。

### 2.7 统一养剑壶标准（2026-09-20）

- 以 `cpa_gourd_ref.png` 为主：朱红底、金色卷纹的葫芦形养剑壶，保留主参考的轮廓、配色与纹饰组织。`cpa_gourd_structure_ref.jpg` 只辅助理解壶形与红绳连接，不能覆盖主参考。
- 腰侧只挂一只适度小巧的壶，以短绳系在腰带上；系点、绳结、壶身重量与衣料接触必须可信。壶体不得放大成主视觉，不得漂浮或垂到膝部。
- 后续所有陈平安图撤除原腰间小布袋及其专用吊绳，只保留主腰绳和养剑壶的短挂绳；不能把布袋移到另一侧或用壶遮住后继续保留。不可增加第二只壶，也不可改为无纹普通棕葫芦、银色壶或复杂兽首雕像盖法器。
- 书箱与壶均转译为项目的深灰线稿、低饱和色块与克制阴影；不把道具参考的摄影光泽或 3D 材质带进人物画风。

## 3. 允许变化与禁止变化

### 3.1 允许变化

- 表情变化：平静、凝神、迟疑、轻微温和、压抑、克制怒意、疲惫、警觉
- 动作变化：站立、侧身、回望、垂眸、抬手、执物、行走、静坐
- 场景变化：湖岸、雨雾、舟上、屋内、渡口、夜色、雪景、岸边泥地

### 3.2 禁止变化

- 禁止重新设计脸型
- 禁止改变五官间距和主比例
- 禁止把眼睛画大一号来换“精致感”
- 禁止把鼻子改短、改挺、改幼态来换“少年感”
- 禁止把嘴唇画得更厚、更艳、更有妆感
- 禁止把下颌改宽、改圆、改成陌生人
- 禁止把整体年龄感画年轻或画老
- 禁止把气质改成偶像风、美型风、妖俊风
- 禁止脱离 `cpa_outfit_variant_06_warm_weather.png` 另起一套通用服装
- `script.rpy` 相关图禁止偏离 `c1_10_cpa_arrival_v14.png` 的该场次服装版本
- 禁止擅自改外袍长度、袖型、内衫结构、裤型、鞋型、绑带体系
- 禁止用旧开放背架、闭合硬箱或普通葫芦替代第 2.6、2.7 节已确认的书箱与养剑壶
- 禁止把当前暖天行路装画成贵气、华丽、精修偶像风穿搭

携行道具统一：背 cpa_bookbox_ref 中的青绿竹编长方敞口箱，四角竹节立柱、藤绳绑扎，侧挂斗笠与备用草鞋；腰侧只挂一只 cpa_gourd_ref 中的朱红金色卷纹养剑壶，壶形与短红绳连接可辅看 cpa_gourd_structure_ref。箱体贴背，肩带连接清楚，壶以短绳系腰带，保持真实受力和接触；撤除旧腰间小布袋及其专用吊绳，保留主腰绳。

## 5. 生成时的负面约束

不要幼态化，不要老化，不要娃娃脸，不要宽下颌，不要夸张 V 脸，不要大眼改脸，不要美妆感，不要偶像风，不要邪魅感，不要妖异感，不要重新设计五官，不要改变年龄段，不要更换服装版本，不要改成贵气长袍，不要改成仙侠飘带装，不要改成厚重冬装。不要开放背架、闭合硬箱、圆背篓；不要腰间小布袋及其专用吊绳，不要双壶、普通棕葫芦、银色复杂兽首壶；不要漂浮道具或断开的肩带、挂绳。

## 6. 出图验收清单

每次新图生成后，都必须按以下顺序验收：

1. 第一眼是否还是 `cpa_face_standard_01` 那个人，而不是“另一个长得像的古风男性”。
2. 脸型是否仍然保持母版的瘦长收束结构。
3. 眉、眼、鼻、口的位置关系是否与母版一致。
4. 年龄感是否仍然稳定在 20-22 岁。
5. 气质是否仍然是沉静、可靠、自持、坚韧，而非风格漂移。
6. 服装是否仍然符合当前场次所对应的固定版本：通用图对齐 `cpa_outfit_variant_06_warm_weather.png`，`script.rpy` 场次图对齐 `c1_10_cpa_arrival_v14.png`。
7. 书箱是否保持青绿竹编长方敞口结构、四角竹节柱、藤绳及侧挂物；箱体与肩带是否贴背受力，转角后结构是否仍一致。
8. 腰侧是否为单只小巧朱红金色卷纹养剑壶，短绳是否连接腰带；旧小布袋及其专用吊绳是否完全撤除、主腰绳是否保留；辅助参考未引入银色兽首雕像盖。
9. 本次变化是否仅为指定表情、动作、场景，且人物与道具都保持项目 2D 画风；未因换道具改变脸或服装。

只要第 1-4 项里有任一项不稳定，或第 6-8 项服装与道具跑偏，就不通过验收，不进入后续使用；不据此自动删除原文件。

## 8. 执行原则

结论只有一条：

陈平安后续所有图像工作，首先是在维护同一个人的身份连续性与当前服装连续性，其次才是做单张画面的表现力。

## 9. Live2D 动画连接与漂移验收（2026-09-13）

用户明确反馈：静态图与母版一致，但播放动画时，刘海、发型和衣带滑动、脱位。本项记录动画连接问题，不据此重画母版、改变发型或简化服装。当前母版目录为合成 PNG，没有可直接用于部件绑定的分层 PSD；本轮未在项目中定位到对应陈平安可编辑模型，因此以下是制作和排查要求，不是已经查实的具体参数故障或完成修复记录。既往同类失败见 `../../Codex/main_menu_background_sop.md` 第 2.2 节。

### 9.1 分层与连接必须一起设计

分出独立图层只解决“哪些像素可以分别动”，还必须明确“这个部件连在哪里、继承谁的运动”。不得把局部裁图整体平移、旋转后直接当作可靠发丝或衣带动态。

| 部件 | 随动与连接关系 | 局部运动边界 |
|---|---|---|
| 主发型体积、发髻、发簪 | 跟随头部，共用正确的头部父级 | 初版不单独飘移，不改变发际线和主轮廓 |
| 可摆刘海、两侧散发 | 发根随头部；局部风动从根部向发梢渐增 | 根部相对头部保持连接，发梢允许小幅滞后；不能整块头发横滑 |
| 腰带主体、腰结 | 跟随腰部／躯干 | 随呼吸和身体动作正常移动，但不被垂绳风动拉离腰部 |
| 腰结下垂绳与末端 | 根部接在腰结，末端逐渐增加摆幅 | 不连同腰结整体平移，不穿过衣料；邻层补足必要遮挡 |
| 书箱、肩带及被手握住的绳带 | 箱体随躯干保持贴背；肩带分别约束肩部、箱体与手部接触位置 | 保持编织箱壁和四角柱的刚性关系，不套用单根自由垂带摆动 |
| 书箱侧挂斗笠、备用草鞋及系绳 | 系点随箱体，挂件围绕各自系点小幅运动 | 不脱离箱体，不穿过人物、箱壁或其他挂件 |
| 养剑壶与短红绳 | 绳根连接腰带，壶颈与绳结保持连接，壶体随重量小幅摆动 | 不把壶当作悬空贴片，不放大摆幅拉断绳结或穿入衣料 |

“固定根部”指根部相对其父级保持连接，不是把根部固定在屏幕坐标。头部转动时发根也必须随头走；身体移动时腰结也必须随腰走。需要移动的区域从原图提取并保留原坐标，只补绘原来被遮挡、运动时将露出的部分。原底图中不能继续保留一套重复的可动发丝／衣带，避免运动时出现重影。

### 9.2 漂移排查顺序

1. 关闭待机动作和物理输入，回到中立状态，确认真实图层合成与母版一致。
2. 单独驱动头部／身体参数，检查发根、腰结、肩带接触点是否继承正确父级；此时还不启用局部摆动。
3. 单独驱动刘海／垂绳参数，检查根部网格和关键形态：局部摆动在根部应为零或满足接触约束，位移从根部向末端平滑增加。
4. 确认结构稳定后再开启物理或风动曲线；检查是否同一参数受到动作、物理、额外脚本的重复驱动，或父级和子级重复写入同一整体运动。没有实际模型证据前，不能断言某一种就是此次原因。
5. 在组合动作的极值、反向和循环接缝处，复核发根相对头部、垂绳相对腰结的连接，检查穿插、重影和透明洞。连接保持和遮挡补底是两项不同验收，均须通过。

初版先验证一个刘海部件和一根垂绳，完成“原图分离 → 补底 → 父级 → 根部约束 → 小幅动作 → 实际运行”后再扩展。不得用减小到几乎看不见的摆幅掩盖错误连接，也不得为了通过自动绑定重画母版发型、改变腰绳结构。

Cubism 官方自动摆动功能提供支点方向与柔软度设置；这些设置需要配合正确的变形器结构，不能替代上述连接验收。[官方自动摆动说明](https://docs.live2d.com/en/cubism-editor-manual/auto-generation-of-sway-motion/)
