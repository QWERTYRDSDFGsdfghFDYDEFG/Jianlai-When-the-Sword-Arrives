## 2. 角色定位与核心矛盾

朱敛的视觉核心不是“老人”或“高手”其中之一，而是两者同时成立：

- 表面是自称老奴、会做饭、会拍马屁、爱说风流话的老厨子。
- 内里是见过庙堂、江湖、战争与人心的旧贵公子、儒将和武道宗师。
- 他经常站在陈平安和裴钱的侧后方，不抢主位，却能随时接住局面。
- 喜剧感来自他明知故演、故意抬戏，不来自丑化或痴傻。
- 严肃时不需要突然变脸，只要笑意收住、眼神落稳，人物重量就应出现。

必须保持：

- 世故但不猥琐。
- 促狭但不轻浮。
- 忠诚但不卑微。
- 老态是面皮与习惯，不是虚弱。
- 武夫力量藏在骨架、下盘、手与肩背的控制中。
- 读书人、旧贵公子、老仆和江湖人的气息同时存在。

禁止偏移：

- 纯慈祥爷爷、胖掌柜、滑稽家丁。
- 阴险师爷、猥琐老色鬼、反派老怪。
- 满身肌肉、虎背熊腰、外放压迫的武夫。
- 提前使用真实年轻面容。
- 仙风道骨的白须仙人或发光高人。

#### 3.0.3 不依赖服装的脸部身份描述

**朱敛当前老奴面皮呈现为外观约六十岁的清瘦东方男性：头骨偏窄而有足够后脑体积，脸部纵向舒展，颧弓是面部最宽处，下颊自然收束，下颌窄而有骨、下巴短圆微收。眉骨中等偏平，眼睛中等偏小、间距约一眼宽，上眼睑略沉，但目光始终清醒灵活；角色右眼比左眼略窄。鼻子中等偏长、鼻梁自然直，鼻翼宽度克制；上唇偏薄、下唇中等，角色右嘴角常态略高，形成看透场面后的轻微促狭感。发际线中等偏高、额角轻退，耳朵中等且贴近头骨。年龄感集中在额纹、眼角、眉间和鼻唇沟，不以满脸刻纹或浑浊眼神表现衰老。**

这段描述只负责“这张老奴脸是谁”，不包含服装、发型造型、道具、光线和场景；生成任何表情、动作或服装差分时，先保持这段骨相不变。

#### 3.0.4 骨相优先级

1. 头骨长宽、颧宽与下颌收束关系。
2. 眼睛大小、眼距和上下眼睑结构。
3. 鼻长、鼻翼宽与嘴宽关系。
4. 下巴形状、耳位和发际线。
5. 固定轻微非对称。
6. 最后才是皱纹、胡须、发丝和皮肤纹理。

如果新图服装很准确，但上述前五项发生变化，仍判定为“不是同一个朱敛”。

### 3.1 年龄感与脸型

项目锁定的视觉年龄（C级美术设定，并非原文明确数字）：

- 外观约 `55–65` 岁。
- 不是七八十岁的衰朽老人，也不能年轻成四十岁上下的成熟俊叔。

脸型必须保持：

- 瘦长、收束的旧脸，脸长明显大于脸宽。
- 额头不宽大，颞侧略收。
- 颧骨存在但不尖锐，下颊偏瘦。
- 下颌窄而有骨，不做方正威严脸。
- 下巴略收，可因面皮和老态出现轻微松弛感，但不能塌陷。
- 皱纹围绕眼角、眉间、鼻唇沟自然形成，不画满脸均匀刻痕。

禁止：

- 圆胖脸、富态掌柜脸、弥勒脸。
- 宽方国字脸、威严大将脸。
- 干尸般凹陷、病态枯槁或妖怪老人脸。
- 夸张鹰钩鼻、尖下巴和反派面相。

### 3.2 眉眼

必须保持：

- 眉形偏长、偏平，尾段略垂或轻折。
- 眉毛黑灰相间，浓度中等，不做白色长寿眉。
- 眼型狭长但不阴鸷，眼裂中等偏窄。
- 上眼皮略沉，眼角有年龄纹。
- 瞳仁与视线必须清醒、灵活、能迅速判断他人。
- 常态眼神带一点笑意和旁观感，像早已看懂却不急着说破。
- 严肃时只需收掉眼尾笑意、视线变直，不应变成凶恶瞪眼。

禁止：

- 永久眯眼、奸笑眼、猥琐偷看。
- 老年浑浊眼、空洞失焦。
- 怒目金刚式大眼或阴鸷反派眼。
- 真实面容版本的醉人桃花眼提前泄露到老奴面皮。

### 3.3 鼻口与胡须

必须保持：

- 鼻梁自然偏直，鼻头与鼻翼不过分突出。
- 鼻部有年龄感，但不能画成夸张鹰钩鼻或酒糟鼻。
- 嘴宽中等，嘴唇偏薄，嘴角控制力强。
- 常态嘴角可略向一侧抬起，形成克制的促狭感。
- 可以保留短而整洁的黑灰短髭 / 下巴短须，胡须必须贴脸、轻薄、有修整。
- 胡须不是唯一识别点；去掉胡须后脸部骨相仍须成立。

禁止：

- 浓密络腮胡、长须、山羊长胡。
- 满嘴黄牙、夸张龅牙、醉汉红鼻。
- 永久咧嘴大笑或油腻舔唇。

## 4. 发型锁定

当前默认发型必须保持（以下均为C级美术设定）：

- 黑灰相间的长发，灰色只作年龄层次，不做满头雪白。
- 头发以实用方式束在后上方或后脑，发髻中等偏小。
- 使用深褐布绳、旧木簪或素色簪固定。
- 额前不做整齐刘海，可有少量向后梳起的碎发。
- 两鬓可有自然灰发和几缕散发，表现行路与做事的生活感。
- 发型整体整洁但不精修，像一个能料理家务、也能随时出手的人。

禁止：

- 披散长发、仙侠高马尾、巨大道髻。
- 金冠、玉冠、华丽发簪、长飘带。
- 满头白发配长白须的仙翁造型。
- 油亮整齐的古偶发套。

## 5. 体型、姿态与武夫隐藏感

必须保持：

- 身高为成年男性中等偏高，但因长期佝偻，看起来比实际矮。
- 骨架偏瘦，不做宽肩壮汉。
- 肩背向前略收，颈部自然前探少许。
- 佝偻不是腰折或残疾，应表现为主动收住身形、长期形成的身体习惯。
- 胸背、腰胯和下盘必须仍然稳定，双脚落地有根。
- 手掌偏长、关节清楚，既像会做饭、木工和杂事，也像能精准控制拳劲。
- 静止时看似松散，行动时能突然变得极其利落。

动作原则：

- 日常站立：双手拢袖、负手、扶腰带或自然垂落均可，重心不能飘。
- 行路对话：陈平安通常稍前，朱敛在侧后半步接话；佝偻仍在，但步幅稳定。
- 严肃接话：肩背不必完全挺直，只让头部略抬、视线落稳。
- 出手或压场：动作幅度可以大，力量来自腰胯与步法，不靠肌肉膨胀。

禁止：

- 拄拐、颤抖、步履蹒跚。
- 严重驼背到无法抬头。
- 健美肌肉、粗壮手臂、外露胸肌。
- 一严肃就突然完全挺直成另一个年轻人。

## 6. 当前通用服装标准

### 6.1 总体方向

当前默认服装是（A级只确认长衫、布鞋等少量事实；以下具体结构与配色以B级推导和C级美术设定为主）：

- 低调老仆 / 行路管事服。
- 宋韵基础结构。
- 灰褐、炭灰、旧青灰、暗棕为主。
- 棉麻粗布与较耐磨的旧布料。
- 层次清楚、方便做饭、赶路和出手。

必须让人看出：

- 衣服不贵，但穿得有条理。
- 有长期使用、清洗和修补痕迹。
- 不是乞丐，也不是仙门长老。
- 即使做仆从打扮，仍有旧时代读书人与管事的分寸。

### 6.2 上装

- 外层为灰褐或旧青灰交领长衫 / 中长袍，右衽关系明确。
- 袖子宽松但不拖地，腕部便于收起做事。
- 内层为炭灰或深褐交领衣，领口形成稳定深浅层次。
- 肩线自然下落，不加垫肩。
- 衣摆长度以膝上下为宜，便于行路和武打。
- 可有小面积补丁、磨白、袖口使用痕迹，但保持整洁。

### 6.3 腰部、下装与鞋履

- 腰部使用深色布带或窄皮带固定，不用玉带和大金属扣。
- 可悬一只小布袋、钥匙串、旧酒壶或做饭用小物，但不得一次堆满。
- 下装为深灰褐宽松长裤。
- 鞋履为旧布鞋或低帮布靴，颜色深，鞋底有真实泥尘。
- 绑腿只在明确行路或动作场使用，不作为华丽武者装饰。

### 6.4 场次变化

- 序-04、序-05：可在通用服装外加临时匪寇围巾、旧短褂或粗布腰封，但不能改变脸和身体身份。
- Chapter 2～4行路：使用通用灰褐行路版，布鞋与衣摆有轻风尘。
- 厨房 / 落魄山日常：允许增加旧围裙、挽袖和做饭工具；围裙不是常驻立绘的一部分。
- 宴席和正式场合：仍然朴素，只比行路版更整齐，不换成华贵公子服。

禁止：

- 白色仙袍、黑金长老袍、盔甲、披风。
- 华丽刺绣、大面积云纹、发光法器。
- 古偶贵公子服、仙门掌门服、网游 NPC 管家服。
- 把临时匪寇装当成永久服装。

禁止：

- 用道具堆砌“隐藏高手”身份。

## 8. 基础表情标准

### 8.1 常态促狭

- 眉眼放松，眼尾有轻微笑意。
- 嘴角略向一侧抬起。
- 像看懂了场面，准备插一句话。
- 不能变成猥琐坏笑。

### 8.2 拍马屁 / 插科打诨

- 表情更热络，眉峰轻抬。
- 可微微探身或拢手说话。
- 笑意服务对白，不挤眉弄眼。

### 8.3 假装震惊

- 用于序-05配合李槐演戏。
- 眉眼与口型可以适度放大，身体踉跄后退。
- 玩家应看得出他在故意抬戏，而不是真被吓住。

### 8.4 收起玩笑

- 嘴角回平，眼神变直。
- 头部略抬，但佝偻身形仍保留。
- 适合“杀一人救天下”、棋盘与规矩、红烛镇计划等场次。

### 8.5 武夫压场

- 眉眼不必凶狠，重点是视线稳定、下盘扎实。
- 面部肌肉收紧幅度很小。
- 不怒吼，不做杀气特效脸。

允许新增：

- 饮酒微醺。
- 看裴钱胡闹时的无奈。
- 做饭时的专注。
- 真正担忧时的沉默。

所有表情必须沿用同一老奴面皮骨相。
