# 朱敛规则脸部网格 v1

## 层级关系

1. 原始脸部母版负责身份、肤质、发髻、胡须与气质。
2. `zl_face_mesh_v1.json` 的478点负责五官语义锚点。
3. `zl_face_grid_mesh_v1.json` 的规则网格负责局部变形与三角面质量。

## 网格规则

- 每个视图使用独立的规则行列网格。
- 只有上下左右相邻的四个有效顶点才能构成一个小矩形。
- 每个小矩形只拆成两个局部三角形；相邻网格交替使用对角线方向。
- 三角形顶点的行号差与列号差都不得超过1。
- 眼睛和内唇是孔洞区域，不生成跨孔洞的矩形或三角形。
- 脸部外轮廓以外、透明像素和其他身体区域的顶点均为无效顶点。
- 禁止为了填补边界生成跨网格、跨透明区域、跨身体部位的长三角形。
- 478点只映射到最近的有效规则网格顶点，不参与最终三角剖分。

## 分镜使用

序-P05第三镜优先调用 `three_quarter` 网格。先用语义锚点对齐脸廓、眼角、鼻尖、嘴角与下巴，再只移动规则网格的局部顶点。禁止直接将正面网格坐标复制到侧转脸。
