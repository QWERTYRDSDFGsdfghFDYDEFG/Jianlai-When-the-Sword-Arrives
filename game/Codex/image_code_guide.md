# 图片代号与写作指南

图片代号用于剧本、分镜、素材检索和 Ren'Py 调用。编号固定绑定用途，换同一用途的图片版本时更新映射，原剧本无需重新编号。

## 入口

- [看图速查页](image_code_gallery.html)：搜索角色、代号、用途；复制写作代号或程序调用；点击缩略图查看原图。
- [图片代号总表](image_code_catalog.md)：角色编号、表情编号、全部已登记图片及状态。
- [唯一数据源](../image_catalog.json)：维护编号、用途、实际路径、采用状态和可调用情况。
- [角色身份索引](character_image_index.md)：仍负责母版与身份标准；代号登记不代表重新确认美术。

速查页可以直接用浏览器打开。页面使用本地原图，无需联网；“可调用”筛选只展示已有程序映射的图片。若需要找母版或界面图，切换为“全部”。

## 编号规则

| 类别 | 格式 | 含义 |
| --- | --- | --- |
| 立绘 | `立绘04·01·01·00` | 角色 / 服装 / 姿势 / 表情 |
| 背景 | `背景01·01` | 固定场景 / 差分 |
| 剧情 CG | `CG01·01·01` | 章节 / 事件 / 差分 |
| 身份、表情页及制作参考 | `参考04·01` | 角色 / 参考条目 |
| 界面图片 | `界面01·01` | 界面组 / 条目 |
| 模型纹理 | `纹理01·01` | 模型 / 纹理条目 |

- 数字至少两位；已有编号不重排、不复用。新增角色不改变旧角色编号。
- 服装在角色内编号，姿势在该服装内编号；表情含义按总表统一。朝向、手势、道具或镜头改变到无法共用差分时，登记新姿势。
- 表情 `00` 仅表示原图表情尚未标准化；不得将它推断成平静、害羞等。`05` 固定表示害羞，但没有对应图片的组合不能调用。
- 站位、镜头缩放、压暗、转场独立于图片代号；同张图放左侧或右侧不产生新资产号。
- 图片版本号仍留在原文件名中，不加入写作代号。停用编号保留历史；更换角色、服装或用途时分配新编号。
- “当前使用 / 候选 / 待修正 / 停用”表示采用状态；“可调用 / 仅参考 / 待制作 / 仅界面”表示用途与接入情况，两者分别记录。候选测试别名可调用不等于正式美术已获确认。
- `game/images/`、`game/lh/`、`game/gui/` 的图片纳入总表；工作区源稿、QA 截图、存档截图、模型内部数据文件不作为剧情图片编号。

## 写作与程序调用

写作或分镜中可以直接标注：

```text
【立绘04·01·01·00，右侧，淡入】
【立绘01·02·01·05，右侧，淡入】（仅格式示例；未登记制作完成前不可调用）
```

写入 `.rpy` 时，从速查页复制“程序调用”。当前已有崔东山测试别名的调用是：

```renpy
show cds o01_p01_e00 at right_medium
with dissolve
# 角色离场：
hide cds
```

保留 `cds` 作为角色标识，因此与旧的 `show cds standard` 混用时会替换同一角色，不会多叠一张。不同角色使用各自标识。此图沿用既有测试素材，不承诺透明背景或新增表情。

也可以直接按中文代号查询。立绘使用 `show expression` 时，建议显式写出该角色的标识，便于检查退场与换图：

```renpy
show expression image_code("立绘04·01·01·00") as cds at right_medium
with dissolve
```

背景与整张剧情 CG 从速查页复制 `scene bg ...` 即可。代号别名仍指向既有图片定义，保留原有缩放。不要把表情拼图、脸部母版或模型纹理当作舞台立绘。

`image_code()` 接受代号中的 `·`、`.` 或 `_` 分隔符。不存在、待制作、仅参考或仅界面的代号会明确报错，不自动改用另一张图。

## 新增与更新

1. 按身份标准与场次需求确认图片用途；检查总表是否已有同一用途的编号。
2. 在 `image_catalog.json` 添加或更新记录，保留已分配编号；填写服装、姿势与差分的具体说明。待制作条目的 `path`、`target`、`alias` 留空。
3. 新背景和 CG 先在 `bg_images.rpy` 注册原始图片；新增立绘使用稳定角色标识注册。仅参考、界面图和模型纹理不建立剧情调用别名。
4. 在仓库根目录运行 `python tools/build_image_catalog.py`，同步程序映射、总表和速查页；不要手改这三份生成结果。
5. 运行 `python tools/build_image_catalog.py --check`，检查重复编号、缺图、引用及生成结果是否同步；再按接入风险执行 Ren'Py lint 和实际画面、存读档验证。

现有图片文件与旧调用继续保留。无需为使用代号批量重命名或复制素材。原有文件名规则仍用于实际文件，稳定代号通过唯一目录映射到文件。
