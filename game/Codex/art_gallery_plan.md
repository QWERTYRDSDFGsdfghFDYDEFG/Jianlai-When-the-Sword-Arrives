# 画像鉴赏接入与验收

日期：2026-09-24。

状态：用户已确认实施，2026-09-24 完成接入与隔离引擎验收。主菜单和游戏内菜单均可进入画像鉴赏，首版按序章累计记录解锁正式回廊图。

## 目标与范围

在主菜单和游戏内菜单增加“画像鉴赏”，集中查看已经累计解锁的正式背景。后续主菜单显示更新的背景时，旧背景仍可在鉴赏中查看。图册按登记条目自动翻页，不限制为当前序章的三个标题阶段。

首版只登记【界面16·04】小宝瓶／陈平安回廊眼神定稿，使用现有 `gui/title_progress/prologue_memory.png`。解锁条件为已有 `academy_farewell` 完成记录；已解锁玩家无需重玩。序章前两个运行占位及其他已否决、退役、测试图不纳入玩家图册。

不添加或改画素材，不改变主菜单背景自动选择、“继续”目标、剧情内容和既有解锁触发点。本轮没有“设为主菜单背景”功能。

## 具体交互

1. 两处菜单均可进入“画像鉴赏”。沿用项目现有字体、暗色旧卷底图及按钮风格，调整主菜单按钮间距以避免新增一项后挤占解锁说明。
2. 图册采用每页六张的缩略图布局，显示已解锁数量及翻页控件；实际条目不足时自然留白，不虚构待制作的章节。
3. 未解锁条目使用不含原图的锁定卡片与“完成序章后解锁”等条件，不泄露图像或剧情标题；全部未解锁时也有明确提示。
4. 点击已解锁缩略图进入完整画面，等比适配窗口；可左右切换其他已解锁图，单图时不出现无效切换操作。返回键、Esc／右键回到图册，再返回原菜单或游戏。
5. 查看图片只读累计记录，不修改进度、不播放剧情、不自动替换菜单背景，也不因看图产生额外解锁。

## 后续收录方式

在 `game/art_gallery.rpy` 的 `story_art_gallery_entries` 追加一条记录，按希望展示的顺序排列。该表是启动时的静态配置，修改后重启游戏生效；游戏运行中只变化累计解锁条件，不增删表项。

- `id`：唯一、长期不变的图册标识；更换同一张图的修订稿不换 ID。
- `title`：解锁后显示的画像名称；用 `_()` 标记可翻译文本。
- `path`：现有正式图片的资源路径；新增资产仍按项目规范登记，图册不扫描素材目录。
- `unlock_field`：保存累计完成事件的 `persistent` 字段名；其值必须为集合、列表或元组。
- `unlock_event`：该图要求的精确事件 ID。
- `locked_hint`：解锁前显示的不剧透提示，如“完成序章后解锁”。锁定时不显示图片与真实标题。

第一张使用 `story_title_unlocks` / `academy_farewell`，直接兼容现有记录。未来独立剧情事件必须先接入持久保存与累计合并，再指定相应字段和事件；不能把临时剧情变量当作累计条件，不能给序章事件表直接追加后续章节。鉴赏页面只读取记录，不负责补发完成事件。

每页六项、页数和前后图片由条目动态计算，无序章阶段上限。大图切换只包含已解锁且资源可读的图片；缺图禁用，不退回展示其他未解锁素材。大图 Esc／右键或“返回图册”关闭覆盖层，保留原列表页；从游戏菜单进入时，图册“返回”继续原剧情。操作栏单独占据底部，完整原图等比显示，不被按钮覆盖。
